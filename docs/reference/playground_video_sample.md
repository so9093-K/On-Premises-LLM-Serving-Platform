# Playground 영상 분석 예제

**영상 분석**은 8초 무음 합성 영상에서 도형의 색상·모양과 등장 순서를 질문하는 예제다. 실제 촬영 영상이나 사용자 데이터를 포함하지 않는다.

## 사용 방법

1. Playground의 **Chat → 예제 보기 → 영상 분석**을 선택한다.
2. 영상을 재생하거나 일시정지하여 입력을 확인한다. 필요하면 **영상 장면 설명 보기**를 펼친다.
3. **영상 입력 제한**에서 현재 모델이 허용하는 파일 개수·크기·길이·프레임 상한을 확인한다.
4. **입력에 적용**을 누르고 질문을 확인한 뒤 **보내기**로 실행한다.
5. 응답이 완료되면 **코드로 사용하기**에서 전송한 요청 JSON과 실행 예제를 내보낼 수 있다.

선택·재생·입력 적용은 추론을 실행하지 않는다. 장면 설명은 접근성을 위한 안내이며 모델 요청에는 포함하지 않는다.

## 지원과 입력 제한

- 현재 모델이 영상 입력과 WebM을 지원하고, 예제의 크기·길이·해상도를 허용할 때 적용할 수 있다. 미지원 또는 제한 초과 시 이유를 표시한다.
- 샘플은 **WebM/VP9, 640×360, 8초, 약 4.1 KiB**의 로컬 정적 파일이다. 브라우저에서 재생하지 못하면 연결 상태와 WebM 지원 여부를 확인한다.
- 표시하는 제한은 현재 모델의 공개 정책이다. 고정 샘플의 메타데이터를 정책과 비교하며, 실제 입력 허용 여부는 Gateway와 Runtime이 판정한다.
- 임의로 첨부하는 영상은 파일 첨부 기능을 이용한다. 이 예제의 길이·해상도 확인은 등록된 샘플을 대상으로 한다.

제작 코드·원본 해시·실측 조건은 [영상 샘플 제작 및 검증](../resources/playground_video_validation.md)에 기록한다.
