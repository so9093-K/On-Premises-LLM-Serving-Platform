# ADR-0060: 로컬 실행은 Git과 독립적으로 소스를 식별한다

## Status

Accepted.

## Context

ZIP·복사본과 Git 저장소에서 같은 운영 명령을 제공해야 한다. Git 정보 없이도
로컬 이미지가 현재 소스와 일치하는지 검증할 수 있어야 한다.

## Decision

1. 기동·상태·종료·포트 변경은 Git을 선택 도구로 취급한다. Git 정보를 조회할 수 없는
   소스는 `local`로 표시한다. Git 커밋 라벨은 빈 값으로 두어 기반 이미지의 커밋을 승계하지 않는다.
2. 공통 모듈이 Docker COPY 입력과 빌드 스크립트의 상대 경로·내용·실행 비트로 SHA-256을
   계산한다. 인증값·모델 캐시·Git 정보·배치 경로는 제외한다. 빌드와 기동은 같은 계산을 사용한다.
3. 로컬 이미지 재사용에는 `ai_model_serving.source_digest` 일치를 요구한다. Git 정보가
   있으면 기존 clean 커밋 일치 조건도 적용한다. 외부 registry digest는 배포자가 지정한 불변 입력이다.
4. 포트 변경은 명시된 소스 경로·텍스트 확장자로 대상을 선택한다. 숨김 파일·캐시·바이너리·
   심볼릭 링크는 제외하고 `.env`는 관리 대상 포트·내부 URL만 갱신한다. 계획·검증·복구는 ADR-0059를 따른다.

## Consequences

내용 해시는 로컬 소스 변경을 식별하며 공식 릴리스나 서명을 증명하지 않는다.
해시 라벨이 없는 이전 로컬 이미지는 다음 기동에서 빌드 캐시를 사용해 갱신한다.
